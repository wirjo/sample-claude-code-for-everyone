# Presentation Generator

Generate structured presentation outlines from any source document.

## What it does

Takes meeting notes, PRDs, research data, campaign briefs, or any document and creates a presentation outline with:
- Compelling title slide
- Clear narrative structure
- Key points per slide
- Talking points and supporting details
- Suggested visuals or data

## When to use it

- Need to present findings from research
- Want to share strategy or plans with stakeholders
- Need to create sales pitch decks
- Have to present quarterly results
- Want to turn dense documents into scannable slides

## How to use it

1. Make sure you have the source document you want to present
2. Run the Skill: `/presentation-generator`
3. Claude will ask what document to use as source
4. Specify the target audience and presentation length
5. Claude generates the outline
6. Review and iterate as needed

## Example

**You:** /presentation-generator

**Claude:** I'll help you create a presentation outline. What document should I use as the source? And who's the target audience?

**You:** Use the meeting-summary.md file. Audience is executives, keep it to 10 slides.

**Claude:** I'll create a 10-slide executive presentation outline from meeting-summary.md.

[Generates structured outline with title slide, agenda, key points, data slides, next steps, Q&A]

## Customization

Tell Claude:
- "Make it more technical" or "Keep it high-level"
- "Focus on metrics and ROI"
- "Add a competitive comparison slide"
- "Include a timeline slide"
- "Start with the problem, not the solution"
